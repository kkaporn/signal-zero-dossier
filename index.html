ORIGINAL GAME CONCEPT / PC FIRST

在失联基地里， 杀出一条不断变化的生路。

《SIGNAL ZERO》是一款以《孤胆枪手》式群怪火力为核心的 3D 俯视角 Roguelite 清怪射击游戏。 用 DNF 式房间地图组织路线，用《重生细胞》式跑局制造变化， 用《合金弹头》式爆炸与 Boss 演出放大爽感。

01

十秒内就要开火

从按下开始到第一次命中，不放长过场。基地的威胁用空间和声音介绍。

02

每扇门都是选择

精英房换高收益，商店房换稳定，风险房换稀有武器。路线本身就是构筑。

03

死亡保留知识

失败损失本轮装备，但保留研究数据。下一轮解锁的是选择，而不是单纯攻击力。

02 / GAMEPLAY LOOP

从一枪到一整局，循环必须层层推进

每一层循环都给上一层制造新的决策，不靠重复刷数字维持时长。

0–8 秒

进入与识别

识别房间类型、出口、敌人来源和可破坏物。

8–45 秒

移动与清怪

瞄准、射击、冲刺、换弹，在敌群中维持移动。

45–70 秒

清场与拾取

决定带走什么、丢掉什么，以及是否冒险探索。

约 25 分钟

整局构筑

组合武器、改装和路线，挑战区域 Boss。

04 / TECHNICAL BLUEPRINT

“2.5D”不是含糊风格，是明确的工程约束

画面使用 3D 资产，玩法发生在稳定地面平面，镜头固定为俯视 3/4 角度。

01

Camera3D · 固定俯视角

不允许玩家自由旋转。相机通过死区和插值跟随，保证大规模战斗的方向稳定。

02

XZ 平面移动 · 8 方向

角色在地面平面上移动，镜头射线转为瞄准点。3D 模型与 2D 操作逻辑分离。

03

房间即场景 · 门即接口

每个房间是独立场景；统一出生点、出口、刷怪组和奖励槽，方便手工设计与随机拼接。

04

数据驱动 · 可验证地图

房间图保存为 Resource。生成后检查可达性、分支数量和 Boss 路径，避免软锁。

07 / SHIP A SMALLER COMPLETE GAME

MVP 的“完整”，不是内容无限，而是闭环完整

第一版必须能从主菜单进入、完成一次跑局、击败 Boss、失败或胜利并保存进度。

MUST SHIP完整性底线
  • 主菜单、暂停、设置、退出
  • 玩家移动、瞄准、闪避、射击
  • 4 类武器与基础改装
  • 5 类普通敌人和 1 个 Boss
  • 3 个区域、12–18 个房间
  • 清房开门与分支地图
  • 单局构筑与永久研究数据
  • 存档、胜负流程和 Windows 构建

  • 第二个 Boss 和隐藏区域
