# SIGNAL ZERO — Development Dossier

Public concept and development-pipeline website for an original top-down 2.5D
roguelite shooter.

The site documents:

- design DNA and product pillars
- the moment-to-moment and run-level gameplay loops
- an interactive DNF-style room graph
- the fixed-camera 2.5D technical blueprint
- art-direction rules
- the full development pipeline and stage gates
- MVP scope and release criteria

All visual elements are original HTML, CSS, and SVG. No assets from the
reference games are used.
